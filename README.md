# 凌皓風 · 互動式聊天

Crushie 風格的 AI 角色扮演聊天網頁。支援多種 AI 後端：

- **Pollinations**（免費 / 無需註冊）
- **OpenRouter**（免費註冊，有 DeepSeek、Llama、Gemini 等免費模型，**推薦**）
- **Anthropic Claude**（付費）

## 功能

- 模擬手機聊天 App 介面
- 兩個快捷按鈕：「推進劇情」「新劇情」
- 用 `/動作/` 輸入語法執行角色動作（會自動轉為 `*動作*` 敘述）
- 對話自動保存到 localStorage
- 重置對話按鈕

## 使用

打開 [GitHub Pages 網址](#)，第一次使用點右上齒輪設定 AI 服務。

### OpenRouter 設定（推薦）

1. 到 <https://openrouter.ai/> 註冊（用 Google 帳號即可）
2. 進入 Keys 頁面建立一個 API Key
3. 在網頁右上齒輪 → 選擇 OpenRouter → 貼上 Key → 選擇模型（DeepSeek V3.1 推薦）
